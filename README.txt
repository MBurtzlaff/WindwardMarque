Windward Marque v0.3.0
A browser pirate strategy game. Add the site to an iPhone home screen from Safari
(Share → Add to Home Screen). Open it online after an update, swipe it closed, and reopen.
New in 0.3: a guided "First Voyage" tutorial (main menu), a Goals / What now? panel,
first-time tips, and a painted look (title screen, sea, islands, towns, ships, battle effects,
parchment-and-wood screens, painted crew portraits).
Saves live in the browser and survive updates. Use Export / Import for a backup file.
Settings can always be put back with ☰ Menu → Reset to phone defaults (or open the page with ?reset=layout).
Fonts: Pirata One and IM Fell English SC (SIL Open Font License, see assets/fonts/).
This is a separate game from Banners of Aldmere.
